## 🚀 Quick Start

### Build & Run
```bash
# Build, install, and launch on device
ktroid run

# Or step by step:
ktroid build debug
ktroid install app/build/outputs/apk/debug/app-debug.apk
```

### Development
```bash
# Add dependencies
ktroid dep retrofit
ktroid dep glide

# Add permissions
ktroid perm internet
ktroid perm camera

# View logs
ktroid logs
```

## 📁 Project Structure

This is a standard Android Project structure. Here is where you should write your code:

### 1. App Logic (Kotlin)
Your main Kotlin code is located here:
`app/src/main/java/{package_path}/MainActivity.kt`

You can add more Activities, Fragments, and Classes in this folder.

### 2. User Interface (Compose)
This project uses Jetpack Compose for UI. Check `MainActivity.kt` for the composable functions.

### 3. Resources
- **Strings**: `app/src/main/res/values/strings.xml`
- **Colors**: `app/src/main/res/values/colors.xml`
- **Images**: Put your images in `app/src/main/res/drawable/`
- **Icons**: Use `ktroid logo path/to/icon.png` to update app icon

## 🛠 Common Commands

### Building
```bash
ktroid build debug          # Debug APK
ktroid build release        # Release APK (signed)
ktroid build bundle         # Android App Bundle
ktroid clean                # Clean build
```

### Device Management
```bash
ktroid emulator list        # List AVDs
ktroid emulator start       # Start emulator
ktroid uninstall            # Remove app from device
```

### Testing
```bash
ktroid test                 # Run unit tests
ktroid test instrumented    # Run instrumented tests
```

### Version Management
```bash
ktroid bump code            # Increment version code
ktroid bump name            # Increment version name
ktroid bump both            # Increment both
```

### Dependencies
```bash
ktroid dep-list             # List all dependencies
ktroid dep-remove <name>    # Remove dependency
```

### Release Preparation
```bash
ktroid signing              # Setup signing config
ktroid bump both            # Update version
ktroid build release        # Build signed APK
```
